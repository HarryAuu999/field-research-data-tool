# AuNote 标注底图生成规范与 Prompt

本文件面向协助用户研究的 AI。目的不是生成“漂亮的人体插画”，而是得到可以**准确辨认位置、直接点选和涂画、多人叠加比较**的稳定底图。

相关流程见 [AI 图片研究配置指南](../docs/image-annotation-ai-guide.md)。现成范例使用项目中的三张耳朵底图：`assets/ear-side.png`、`assets/ear-side-section.png`、`assets/ear-back.png`，以及 [耳机接触与疼痛示例问卷](../examples/ear-image-range-test.json)。

## 生成前，先确认

只询问用户尚未说明、且会影响正确性的内容：

- **研究对象**：人体哪个部位，或哪一类产品/物体；需要记录接触、疼痛、压力感、摩擦，还是其他空间位置？
- **标注面和视角**：正面、背面、左侧、右侧，或指定局部视角；某些区域如果无法在同一投影中清楚看见，应说明并建议分图。
- **素材来源**：用户已有底图，还是希望 AI 生成？优先复用符合要求的现成图片；不要未经确认自行替换用户图片。
- **分析目标**：不同图片、朝向、人物/产品条件是否要分别统计；是否有疼痛等级等独立层级。

选定底图后，后续所有受试者都应使用**相同的图像和坐标基准**。

## 通用底图生成 Prompt

将下列参数替换为研究实际需求，再发送给具备图片生成能力的模型；如果用户提供原图/3D截图，应明确要求以其为**几何与方向参考**，而不是凭空重新构造结构。

**可替换参数**

- 研究对象：{OBJECT}
- 具体部位：{REGION}
- 视角与朝向：{VIEW}
- 是否需要保留相邻身体/物体区域：{CONTEXT}
- 背景基调：{BACKGROUND}
- 比例与画幅：{ASPECT_RATIO}

**生成 Prompt：**

> 创建一张用于 AuNote 用户研究中“点位与范围标注”的干净二维底图。
>
> 主体为 {OBJECT} 的 {REGION}，镜头严格处于 {VIEW}。保证部位朝向与投影关系准确，不擅自改成更有戏剧性的 3/4 视角；优先让需要标注的表面完整、清楚地暴露。与研究对象相连的 {CONTEXT} 保留必要的真实几何连接，不引入不合理的突起、折线、断裂或额外结构。
>
> 视觉风格：克制、清晰、轻医学/产品示意风格；中性浅灰色或柔和灰阶，光滑连续的大面积明暗变化；有限的柔和立体感，简洁明确的结构轮廓；画面干净，适合手机触控标注以及后期叠加彩色热力图。
>
> 禁止照片质感、皮肤毛孔、素描笔触、写实噪点、复杂背景、头发遮挡、强烈阴影、发光边、热力色、预设标记、网格、坐标、文字、箭头、图例、水印和设备遮挡。不要为了美观牺牲真实的空间关系。
>
> {BACKGROUND}。{ASPECT_RATIO}。请只输出独立、无任何 UI 的底图。

## 耳朵范例：左耳纯侧视

研究：耳挂式耳机佩戴接触与疼痛标注。

> 使用上述通用规范生成一张 **左耳的严格外侧正投影视图**。观察者站在左耳正外侧，视线近似垂直于头部矢状面，不从脸的前方或脑后观察，不使用 3/4 视角。耳轮、耳甲、耳屏、耳垂结构清楚、连贯。浅灰色头侧皮肤表面自然延伸并充满背景，不绘制头部、脸颊、颈部的外边界线，不出现倾斜薄板、三角楔块或收腰式头颈轮廓。耳部位于画面易于标注的核心区域；不画耳机、标签及热力颜色。

若目标改为**耳廓背面接触**，应单独生成从耳朵背后观察的视图，优先暴露宽阔、平缓的耳背接触面与耳后沟；不可用从脸前方看到的耳廓正面假冒背面。需要严格对应真实产品几何时，以同一 3D 模型渲染或实测图片为基础更可靠。

## 验收标准（生成后逐条检查）

1. **方向准确**：左/右、前/后、侧视无反转；必要区域可见。
2. **几何合理**：耳朵/身体/产品轮廓连续，无凭空添加的褶皱、凸起、弯折。
3. **方便标注**：主体足够大，细节能辨认，画笔覆盖后仍看得见位置。
4. **颜色克制**：中性灰度，无预设热点，不与将来的热力图颜色竞争。
5. **基准固定**：图像尺寸、朝向、裁切稳定；多人数据不混用不同底图。
6. **用前确认**：先向研究者展示图片，确认正确再嵌入问卷，不以 AI 自评代替人工验收。

**限制**：生成图片可以用作主观位置记录的示意底图，但不能仅凭生成图宣称毫米级人体测量精度；若研究涉及实际尺寸或跨视角严格配准，应使用可追溯的实物照片、扫描或 3D 渲染。

## 最快测试方法

开启一个没有项目聊天背景的 AI 对话，发送：

> 我想用 AuNote 调研耳挂式耳机的接触与疼痛区域。这是项目：https://github.com/HarryAuu999/field-research-data-tool 。请先阅读 docs/image-annotation-ai-guide.md 和 prompts/annotation-base-image.md。现在我没有标注底图，你应该先如何帮助我？我需要左耳侧面和耳背两个视角。先给我确认步骤与底图提示词，暂时不要生成 JSON。

检查它是否会主动确认图片来源、研究视角、层级、底图固定和当前导入方式；确认后再实际生成图片，用上面的 6 条标准验收。
