# 图片角度采集、分析与导出

V1.4.10新增可复用的 `imageAngle` 题型与 `angleDistribution` 分析模块。不替换出厂问卷，不自动安装角度测试问卷，也不改动已保存问卷、草稿或样本。

手动测试时，从问卷管理导入 [`ear-image-angle-test.json`](../examples/ear-image-angle-test.json)。其底图已经随应用缓存，因此可在正式版离线使用。开发者也可在本地打开 `/preview/image-angle.html` 加入并选择该单题问卷；该辅助入口仅允许localhost，同 id + version 的既有问卷不会被覆盖。正式应用初始化不读取它。

## AI研究协作与复用

研究涉及佩戴倾角、产品方向、关节示意角或其他固定底图上的二维单角度时，AI应主动建议本模块；不得把耳朵、C桥或本例坐标写死成通用规则。先与用户确认底图、圆心、0°基准、正负方向、范围、步长和分箱组距。缺少这些信息时只提建议，不自行生成看似完整的配置。不可将360°环绕方向、三维姿态或每人的可接受范围当作本模块已支持的能力。

配置使用 `analyses` 数组，可同时包含 `angleDistribution`、`descriptiveDistribution`、`categoricalFrequency`、`imageRangeHeatmap`，每个模块只引用适合的题型；旧式单对象 `analysis` 仍兼容，不能与 `analyses` 同时使用。通用AI入口见[问卷转换指南](questionnaire-ai-guide.md)。

## 问卷配置与保存

新题型 `imageAngle`，配置样例以 `examples/ear-image-angle-test.json` 为准。每道题独占一页，底图包含 `src`、原图 `width/height`；`angle` 的字段如下：

| 必填配置 | 含义 |
| --- | --- |
| `center` | `[x,y]`，相对原图宽高的0～1归一化圆心 |
| `zeroDegrees` | 基准方向，以向右为0°、向上为90°的数学角度定义；本例180°表示向左 |
| `rotation` | `counterclockwise`逆时针／`clockwise`顺时针；本例从向左转到向下为正90° |
| `min/max` | 控件允许的角度范围；递增且跨度不超过180°，本例−20～90° |
| `step` | 调节步长，正数且能等分范围，本例1° |
| `radius` | 指示线长度和图表最大半径，相对原图宽度，本例0.32 |

本例直线表示耳夹C桥方向。圆心按用户示意图暂定为 `[0.54, 0.528]`，在实际图上验收后可微调。

每份答案是 `record.answers.wearAngle = 37` 这样的数字（单位度），未选择为 `""`。初始线虽显示在水平位置，但不会自动记录0°；拖动滑块或点按滑块才确认数值，“清除”恢复未选择。零度和负角度都是有效答案。每个新样本从未选择开始。

`required` 沿用既有规则；本地测试问卷未设置为必填。专用题的文字、必填及几何配置由JSON定义；PWA可复制、排序、删除，通用问题编辑器不修改内部配置，复制时完整保留配置。

Responses中一条样本一行、角度一列，表头注明“°”，答案以Excel数值导出。仅在有角度题时增加AngleFields工作表：每题一行，包含题目ID、Responses中的1起始列号、图片路径／尺寸、圆心、基准方向、角度范围及步长等，供电脑分析重画。没有重复每份样本的几何配置。图片使用项目assets文件；嵌入式图片需随问卷JSON提供，不将大段data URI塞进Excel单元格。完整JSON备份包含底图及几何配置；不增加数据库store或迁移，不保存滑块操作路径。

## 分布分析

在 `analyses` 中加入 `{"type":"angleDistribution","binWidth":10,"fields":[{"id":"wearAngle"}]}`，可与既有数值、频数、热力图模块并列使用。旧 `analysis` 单对象也可使用该类型，但两种顶层配置不能共存。

每条有效记录贡献一个角度。空值、非法数字、范围外及不符合步长的值不进入统计。`binWidth` 须等分字段范围，最多180组；除最后一组包含上限外，各组采用左闭右开区间，避免边界重复计数。

底图上绘制中心留空的极坐标直方图：方向表示角度，中心留空半径为图表最大半径的35%；柱形从标记0人的基准弧向外增长，增长长度与人数线性对应，扇形面积和中心留白不表示人数。同一分析配置的多个字段共享人数尺度。填充不透明度80%，无描边；相邻10°分组间留1°视觉间隙，更细组距使用不超过组距10%的间隙，分组和计数不改变。中心内的实线表示平均数，水平基准虚线表示0°，图例使用与图内同样式的SVG线段。卡片按两列显示样本数、平均数、中位数、样本标准差（n−1分母）；后三项单位为度，最多显示两位小数，单个样本的标准差显示“—”。详细统计中提供Min、Max、P5、P10、P25、P75、P90、P95。百分位复用现有R7线性插值，不拟合正态分布或KDE。

SVG使用原图坐标，缩放保持宽高比，不能直接在归一化x/y空间计算角度，否则非正方形图片会产生角度变形。图表可点按扇形柱，以黑色轮廓描边选中，并在图片内部底端显示白描边黑色粗体的人数及有效样本占比，不改变页面高度；键盘聚焦／回车也可查看。点击其他位置或按Escape同时清除选中与说明，未选中时不显示说明。“详细统计数据”标题使用黑色加粗，展开显示Min、Max和P5、P10、P25、P75、P90、P95。角度滑块采用35.2×22px跑道圆拖动钮（原32×20px增大10%），轨道两端为圆头；其他题型滑块暂不改动。

未来可换图、换圆心与基准方向复用；当前只支持固定参考、有限区间的二维单角度，不支持360°环绕统计、三维姿态、每人多次角度或个人可接受角度范围。这些需求不能仅扩大min/max后宣称支持。

## 从导出Excel复现角度图

1. 读取AngleFields的每题配置，按`responseColumn`（从1起）关联Responses的数值列，不依赖可能重复的问题标题。每行记录贡献一个样本；空白、非数值、越界及不符合步长的值剔除，0和负数有效。
2. 分箱组距取问卷的`angleDistribution.binWidth`，因此分析时一并提供问卷JSON；不能从图形外观推测组距。箱号为`min(组数−1, floor((角度−min)/binWidth))`，最后一组包含max。
3. 计算均值、样本标准差和R7百分位；PWA的参考实现是`js/image-angle.js`与`js/statistics.js`。不自动拟合正态，也不把最高柱当成均值。
4. 圆心为`(centerX×imageWidth, centerY×imageHeight)`；方向为`zeroDegrees + 角度×符号`，逆时针符号+1、顺时针−1；端点为`(cx+r×cosθ, cy−r×sinθ)`。使用原图比例，不拉伸x/y。
5. 绘图保持35%中心留空、柱长表示人数、不透明度80%与无描边留缝；平均数实线、0°虚线。不同字段共用人数尺度的规则与PWA一致。可直接复用模块生成SVG，无需重新研究绘图算法。
6. 内置底图在assets；内嵌底图需从原问卷JSON取出，Excel不重复存储图片。仅有Excel而缺少自定义图片或分析配置时，应向用户索取缺失文件，不猜测几何定义。

## 针对性验证

`node tests/image-angle.mjs` 检查角度几何、空值／0°、边界分箱、校验和复制。启动本地服务后以 `AUNOTE_TEST_URL` 指向服务，运行 `node tests/image-angle-e2e.mjs`，覆盖真实触控滑块、草稿、多个样本、样本修改、数值Excel和离线恢复。测试使用独立浏览器上下文。
