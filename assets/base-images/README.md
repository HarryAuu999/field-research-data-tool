# 人因研究通用底图库

供研究者和AI挑选、贡献用于位置、范围或二维角度采集的底图。这里是资源目录，不是PWA中的自动图库；新增图片不会自动进入用户问卷或离线缓存。

新文件放入相应分类，例如 `hand/palm-left-v1.png`。已有耳图不搬动、不复制；其名称、预览及来源状态见耳部索引。

## 使用方式

1. 先确认视角、左右侧、研究指标及图片是否适合，再配置问卷；AI不要把其他产品或身体部位的坐标直接照搬。
2. 使用已随应用发布并由Service Worker缓存的同一默认底图时，直接用`./assets/...`引用，不重复内嵌；自定义底图使用内嵌data URI。两者均记录正确的原图宽高。仓库里有文件不等于PWA已经离线缓存它。
3. 开始采样后固定图片、朝向、裁切和坐标定义。需要更改时增加新文件和问卷版本，不覆盖旧资源。
4. 资源贡献与应用发布分开：新增目录、说明或图片本身不改变用户问卷；要把新资源内置PWA，需另行确认、修改缓存清单并验证离线能力。

## 贡献底图

通过Pull Request提交，由项目维护者审核后合入。不要提交研究记录、参与者照片或其他个人信息。每张图请附：

- 名称、适用场景、视角和左右侧；
- 原图宽高、建议朝向和必要的坐标基准；
- 作者或来源链接、明确的使用与再分发许可，以及所需署名；
- 如由AI生成，注明生成方式及使用限制，不宣称它具备真实人体测量精度。

新贡献优先使用原创或有清晰开放许可的资源；现有图片的许可不能据此推定。贡献流程见 [CONTRIBUTING.md](../../CONTRIBUTING.md)，绘图建议见[底图生成规范](../../prompts/annotation-base-image.md)。
